# Data Science 2026 Team Project

### Quick Start

```bash
# clone the repo 
git clone --recurse-submodules https://github.com/yydderf/ds2026.git
cd ds2026

# check part 1 data and download the H&M dataset into part2/hnm/
./fetch.sh

# create .venv and install dependencies
uv sync
```

#### Without uv

Use a regular virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
